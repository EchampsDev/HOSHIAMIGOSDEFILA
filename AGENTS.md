# Reglas de contribución

- Trabaja por módulos autorizados; no implementes fases futuras por anticipado.
- Mantén el dominio separado de la interfaz y evita llamadas directas de Firebase desde componentes.
- Preserva los datos originales y trata consentimiento y moderación como información de dominio.
- Evita acciones destructivas. No uses `git reset --hard`.
- Ejecuta pruebas, lint y typecheck antes de concluir cambios.
- Actualiza la documentación si cambia la arquitectura o el modelo de datos.
- No hagas deploy ni `git push` sin autorización explícita.
- No tocar VIGÍA: este repositorio es independiente.
